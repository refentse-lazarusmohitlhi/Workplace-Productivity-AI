# AI Workplace Productivity Assistant

An AI-powered workplace productivity web application designed to help professionals manage tasks, conduct research, and improve productivity through intelligent AI assistance.

## Project Overview

The **AI Workplace Productivity Assistant** is a modern, responsive SaaS-style web application that brings essential workplace productivity tools into one platform. It provides AI-powered task planning, research assistance, and an interactive chatbot through a simple, user-friendly dashboard.

The application is designed for immediate access without requiring users to register or sign in.

## Features Implemented

### 1. AI Task Planner

* Generate personalised daily and weekly schedules.
* Organise and prioritise tasks.
* Manage workloads based on urgency and importance.

### 2. AI Research Assistant

* Summarise research topics and articles.
* Accept article text and URLs as input.
* Generate key insights and recommendations.

### 3. AI Chatbot

* Interactive AI workplace assistant.
* Responds to workplace-related questions and prompts.
* Provides relevant, context-aware AI-generated responses.

### 4. User Interface

* Modern SaaS dashboard layout.
* Sidebar navigation.
* Responsive desktop and mobile design.
* Light blue, red, and white colour scheme.
* No registration or login required.

### 5. Responsible AI

* Includes a responsible AI disclaimer.
* Encourages users to verify AI-generated information before professional use.

## Technologies and Tools Used

* **Lovable AI** – AI-assisted application development.
* **React** – Frontend application development.
* **TypeScript** – Type-safe JavaScript development.
* **Tailwind CSS** – Responsive styling and UI design.
* **AI API Integration** – Dynamic AI-generated responses.
* **GitHub** – Version control and project hosting.


## Setup Instructions

### Prerequisites

* Node.js installed.
* npm package manager.
* Git installed.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY-NAME.git
```

**2. Navigate to the project directory**

```bash
cd YOUR-REPOSITORY-NAME
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

If your project uses an AI API, configure the required environment variables using the integration's recommended secure setup. Never commit secret API keys to GitHub.

**5. Start the development server**

```bash
npm run dev
```

**6. Open the application**

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
